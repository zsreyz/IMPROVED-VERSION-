// Modern pattern for AI API calls
async function askAI(prompt) {
  try {
    const res = await fetch('https://api.groq.com/openai/v1/chat/completions', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${process.env.GROQ_KEY}`, // backend!
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        model: 'llama3-8b-8192',
        messages: [{ role: 'user', content: prompt }],
        stream: true  // enable streaming
      })
    });
    const data = await res.json();
    return data.choices[0].message.content;
  } catch (err) {
    console.error('AI call failed:', err);
    throw err;
  }
}

Streaming is what makes AI chat feel instant — text appears word by word like a typewriter instead of waiting 5+ seconds for the full response. Use Server-Sent Events (SSE) or ReadableStream with fetch. The Vercel AI SDK abstracts all of this beautifully.
// Streaming AI response in React
async function streamAI(prompt, onChunk) {
  const res = await fetch('/api/ai', { // backend proxy
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ prompt })
  });
  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    const chunk = decoder.decode(value);
    onChunk(chunk); // update React state with each chunk
  }
}

Never put AI API keys in your frontend. Build a backend proxy: your React app sends a request to YOUR server, your server adds the secret key and forwards to the AI API, returns the response. This is the correct architecture for any production AI app.
// Express.js AI Proxy Route
app.post('/api/ai/chat', authMiddleware, rateLimiter, async (req, res) => {
  const { messages } = req.body;
  // Validate input server-side
  if (!messages || !Array.isArray(messages)) {
    return res.status(400).json({ error: 'Invalid input' });
  }
  const response = await fetch('https://api.groq.com/openai/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.GROQ_API_KEY}`, // secret!
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ model: 'llama3-70b-8192', messages })
  });
  const data = await response.json();
  res.json(data); // forward to client, key never exposed
});

One malicious user can send 10,000 AI requests and bankrupt your startup overnight. Rate limiting must happen server-side (client-side limits are bypassed in seconds). Use per-user AND per-IP limits. Store API keys in environment variables — never hardcoded.
// express-rate-limit setup
import rateLimit from 'express-rate-limit';
const aiLimiter = rateLimit({
  windowMs: 60 * 60 * 1000, // 1 hour
  max: 50, // 50 AI requests per user per hour
  keyGenerator: (req) => req.user?.id || req.ip,
  message: { error: 'Rate limit exceeded. Try again in 1 hour.' }
});
app.post('/api/ai/chat', authMiddleware, aiLimiter, chatHandler);

Founder Mindset

The mental models that separate successful founders from the rest

🔥

Ship Before You're Ready

Every day you wait is revenue lost. Your MVP will be ugly. Ship it anyway. Real users teach you more in one week than 6 months of planning. The market is the only opinion that matters.

🧩

Problems First, Code Second

Fall in love with a problem, not your solution. The code is a tool. The best founders are problem hunters — they obsess over customer pain, not tech stacks. Talk to 10 potential customers before writing a single line.

📡

Build in Public

Share everything — wins, failures, experiments, code snippets. Your audience becomes your testers, investors, and first customers. Pieter Levels built NomadList by tweeting about it before it was finished. Vulnerability is a distribution strategy.

🎯

Constraints Create Creativity

No team. No budget. Only free tools and 2 hours a day. These are your superpowers. Your $500M competitor has 50 engineers and moves slower than you. Constraints force elegant, simple solutions that users actually understand.

🔄

Consistency Beats Intensity

2 hours every single day beats 14-hour weekend sessions. The compounding effect of daily practice separates those who make it from those who burn out in month 3. Your coding skill 12 months from now depends on what you do today.

💡

Use AI as Your Co-Founder

Every great founder today has AI as their secret weapon. Claude writes your code, generates your marketing copy, reviews your architecture, and helps you think through problems at 2am. The founders who win are those who use AI 10x more than their peers.
